# MDMOT Offroad & Enduro – Konzept-Landing-Page

Moderne, mobile Landing-Page als Konzeptentwurf für MDMOT Offroad Enduro
(Daniela Knöpfle, Balzhausen), erstellt auf Basis der Inhalte der bestehenden Website.

- **Online:** https://vatterott.github.io/mdmot/
- **Ausbau:** eine HTML-Datei (`index.html`), keine Abhängigkeiten, läuft offline
- **Technik:** responsives Layout, Sticky-Nav, Scroll-Animationen, SEO-Meta-Tags
- **Bilder:** `assets/` (Originalmaterial der MDMOT-Website)
- **Veröffentlichung:** GitHub Pages (Branch `main`, Wurzel)
